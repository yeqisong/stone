### 1.2 db/connection.py — 双引擎

- `async_engine`（asyncpg）：FastAPI 依赖注入 `get_db()`；prod pool=5 / dev=1。
- `sync_engine`（psycopg2）：crawler/scripts/后台线程用 `get_sync_db()`；pool=5, overflow=10。

### 1.3 task/manager.py — TaskManager 统一任务机制

线程安全单例。**所有长任务**（DAG 流程 / 补数 / 特征计算 / 统计 / 模型训练）的进度跟踪中枢：

- **并发控制**：全局 `MAX_CONCURRENT=5`；`_flow_locks[flow_id]` 同流程互斥（重复触发→429）。
- **Task / TaskNode**：`task-{uuid8}`，节点状态机 `pending → running → success/failed`，携带 log_id（关联 dag_run_log）、progress_pct、rows、detail、error。
- **流转 API**：`create_task → start_task → update_node（自动算总进度）→ complete_task / fail_task（释放锁 + 唤醒 WS）`。
- **启动自愈**：heartbeat 超 5 分钟的 running 日志标 failed（"服务器重启，任务中断"）。

### 1.4 app/signal.py — 线程↔协程桥梁

`asyncio.Event` + 主循环引用：后台线程（DAG/补数/特征）通过 `call_soon_threadsafe` 唤醒 WS 广播协程，实现事件驱动 + 超时兜底（运行 2s / 空闲 30s）。另含任务终止信号（`_stop_requests` set + per-run threading.Event）。

### 1.5 app/ai/ — DeepSeek Function Calling

- `deepseek_client.py`：OpenAI 兼容；Key 回退读 strategy_config.global_preference.params.deepseek_key；连败 3 次降级为快捷菜单。
- `tools.py` 8 个工具：get_my_portfolio / get_stock_detail / get_buy_signals / get_data_status / get_strategy_config（query 类直连 DB）；confirm_add_portfolio / confirm_set_preference（write 类**只生成确认卡片不落库**）；trigger_recalculation（admin）。

### 1.6 app/feishu/ — 飞书 Bot

`POST /webhook/feishu`：challenge 应答 → HMAC-SHA256 签名校验 → 文本消息走 AI 对话（系统上下文注入实时持仓/信号/数据状态）→ tool_calls 执行 → write 类返回 interactive 确认卡片 → **用户点卡片按钮**才真正落库（confirm_add：UPSERT portfolio + history；confirm_preference：读后 merge 更新偏好，保留 deepseek_key）。

### 1.7 app/kepl/ — 表达式解析器

Lark LALR(1)：`+-*/`、括号、NUMBER/BOOL/CNAME/负数字面量 → KepLAST（FieldRef/NumLit/BoolLit/FuncCall/BinOp）。**32 个算子 = 25 时间序列 + 7 截面**；`GET /api/kepl/functions` 为目录单一事实源（`_OPERATOR_DOCS` 文典与注册表强校验，AI 上下文与 Monaco 补全同源）。

- **时间序列（25）**：ma/ema/rsi/std/atr/pct_change/dif/dea/macd_hist/boll_upper/boll_mid/boll_lower + v3.7 新增 ref（负偏移=未来，显式防 shift 方向 bug）/hhv/llv/ts_quantile/ts_rank/slope/rsquare/resi/imax/imin/ts_corr/max2/min2
- **截面（7）**：avg/sum/max/min/rank/quantile/zscore
- v3.7 清理：删除 7 个只有文档没有实现的"幽灵算子"（roc/bias/return_n/corr/boll/sma/obv）；语法补 `?arg: expr | MINUS NUMBER -> neg_num`（LALR(1) 无冲突）

### 1.8 strategy/indicators.py — 技术指标

纯 numpy/pandas：sma/ema/**rsi**（除零处理：严格上涨=100、横盘=50）/**bollinger_bands**（ddof=0 总体标准差，对齐通达信/TA-Lib）/macd/atr/obv/周月聚合。

### 1.9 strategy/ — 策略层 + 回测引擎 v2（v3.7 新建包，Qlib 移植）

**strategy/strategy.py**（信号 → 订单）：
- `SignalStrategy`：事件驱动退出（止损/止盈/trailing/持有到期）+ 等额预算整手买入；`same_day_budget=True` 时买入预算=当日盘后净值（现金+卖出净额估计+持仓收盘估值，已生成卖单的持仓不重复计市值——纸面口径）
- `TopkDropoutStrategy`（移植 Qlib）：固定 topk 持仓 + 每日换血 n_drop + **合并排序防高卖低买**（last ∪ today 降序取末 n_drop）+ `hold_thresh` 最少持有天数

**strategy/backtest/**（五模块，纯 Python + dataclass；设计中的 executor.py 并入 engine.py）：
- `models.py`：TradeConfig（comm/st_tax/slip/impact_cost/min_cost/vol_limit/deal_price/forbid_all_trade_at_limit/cash_delay/downsize_buy）/Order/Fill/Position/DailyRecord/BacktestResult
- `exchange.py`：可交易性（停牌=当日无行情行；涨跌停 limit_flags 复用）/成交价/费用（最低佣金+冲击成本平方模型+成交量裁剪）
- `account.py`：现金/持仓/净值/换手；**cash_delay 延迟结算**（卖出所得次日到账）；卖出记录 `gross_win=卖价>买价`（v1 win_rate 口径）
- `engine.py`：先卖后买两轮撮合、BUY 逐笔立即入账（v1 逐笔递减语义）；`run_backtest(account=...)` 种子账户 + trades/records 快照切片（纸面组合续跑复用同一账户）
- `report.py`：`risk_analysis`（sum/product 双模式，N=238）、`alpha_beta`（对沪深300 回归）、`performance_report`（超额年化/日均换手/win_rate_pos）

**strategy/models/double_ensemble.py**：DEModel（LightGBM，Qlib DoubleEnsemble 移植）——子模型循环、N×T 逐树 loss 曲线、SR 样本重加权 1/(decay^k·bin+0.1)、FS permutation 特征筛选；**早停必须关闭**（excess 标签 MSE 纯噪声，早停会掐死弱信号子模型）。

**统一入口（scripts/pipeline.py `_backtest`）**：pred 模式走 v2 内核并返回 v1 口径 dict（total_trades 只计卖出、win_rate 按 gross_win）；ideal/seed 基线保持 v1 引擎。评估入口（attribution/scan/WF/置换检验）默认 engine='v2'。

## 2. crawler/ 采集层

### 2.1 adapters/ — 数据源抽象

- `base.py`：标准化 dataclass（KlineRow/IndexKlineRow/FundamentalRow/StockInfo，volume=股、amount=元）；`DataSourceAdapter` 抽象基类 7 方法；`code_to_exchange`（6→SSE，0/2/3→SZSE，4/8/9→BSE）。
- `manager.py`：DataSourceManager — priority 升序注册（tushare=5 → baostock=20，AKShare 已于 v3.2 删除），`check_all_health()` 带 300s TTL 缓存，`get_source()` 返回首个健康源，`fetch_with_fallback()` 异常自动切换。
- `tushare_adapter.py`：限流 1.3s/次；K 线双路径（短区间按日期全市场 / 长区间按股票 100 只/批）；`_enrich_kline_batch`（50只/批 daily_basic+adj_factor）补 **close_hfq=close×复权因子** 与 turnover；北交所 `.BJ` 映射；基本面 daily_basic 按最近工作日全市场拉取；另含 top_list/moneyflow/hk_hold/margin_detail/holder_number 扩展方法（**未接入链路**）。
- `baostock_adapter.py`：串行拉取（单 TCP 非线程安全）；K 线两次查询合并（adjustflag=3 不复权 OHLCV+turn → adjustflag=1 后复权 close）；`download_fundamentals` 的 trade_date 取**数据最新交易日**（与 tushare 最近工作日口径对齐，避免周末双行）。

#### 数据源架构（v3.2.1：主源 + 补充器）

**TuShare = 唯一主源**（按交易日全市场拉取，每交易日 3 次调用：daily + daily_basic + adj_factor）：
- daily_quote / index_daily_quote：daily / index_daily / fund_daily 按日全市场，close_hfq=close×adj_factor（97.8% 覆盖），turnover 来自 daily_basic
- stock_fundamentals：daily_basic 22 字段
- stock_master：stock_basic（1次/小时限制，daily 降级）
- 停牌股自然缺失、退市股历史天然覆盖（T 日上市 t 日退市，T-t 数据完整）
- **配额**：tushare_quota 表 + TushareQuota 计数器（50次/分、8000次/天，北京时间自然日）；
  状态页展示剩余配额/风险等级；补数任务按剩余配额预算（<10 次自动收尾，断点明日续跑）

**Baostock = 字段补充器 + 日历源**：
- fetch_fundamentals_extra：补 roe/revenue_yoy/profit_yoy（COALESCE 不覆盖已有值）
- fetch_etf_hfq：补 ETF 后复权 close_hfq（tushare fund_adj 需高积分）
- get_trade_calendar：交易日历唯一同步源
- baostock 不可用 → tushare 主字段照常入库，缺口留待状态页补数修复

| 表 | 协作机制 |
|---|---|
| **daily_quote** | 全部 tushare（含复权）；ETF close_hfq 由 baostock 补充器补齐；UPSERT is_suspended=false + close_hfq 空值保护 |
| **stock_fundamentals** | tushare 主字段 + baostock 补 3 字段（ROE/营收/净利），逐字段 COALESCE；market_cap 缺失时从 daily_quote 补全 |
| **stock_master** | 唯一实现 BackfillManager._run_stock_master（code_to_exchange + COALESCE + 全字段） |


### 2.2 backfill.py — BackfillManager 历史补数

单例 + 全局单任务锁。任务类型：`kline / index / etf / fund / fund_history（基本面 PE 历史回填）/ calendar / stock_master`（indicator 已废弃）。

**K 线补数核心机制**：
- 断点续传：force→空跳过集；单日→查当日 DISTINCT code 跳过已有；多日→靠 UPSERT 幂等。
- **续传阈值（v3.2.1 修复）**：按日判断"是否跳过"用**上市日感知基线** —— 该日已上市股票数 × 80% 与当日行数比较（旧逻辑用"全部活跃股票 × 80%"，老年份永远达不到导致无限续传）；`listed=0`（无股票上市）也视为完成。
- **批次写入隔离（v3.2.1 修复）**：writers 内每批 SAVEPOINT，单批失败 ROLLBACK TO SAVEPOINT 后继续，防止一批异常毒化整个事务（曾因 index_code 超长导致整批静默丢失）。
- 自适应并发：内存 >90% 批次-1 / <70% +1（上限用户 batch_size）；每批 ThreadPoolExecutor(1) + 180s 轮询超时（轮询中持续写心跳 + WS 推进度）。
- 跨年分段：区间 >365 天按自然年拆分；失败自动 relogin 重试一次。
- **停牌标记**：仅批次拉取成功时，缺失且已上市（ipo≤end）的股票写 `is_suspended=true` 全零行；失败批次不写（防止断点续传永久跳过）。
- 重启自愈：running/cancelling 孤儿任务标 failed。
- fund 补数：`fetch_fundamentals(None)` 全市场 → `writers.batch_upsert_fundamentals`（与 DAG fund 节点同一写入路径，含市值补全）→ 行业跨表回写 stock_master。

### 2.3 writers.py — 批量 UPSERT

`batch_upsert_kline`（**真实数据 is_suspended=false 清旧停牌标记；close_hfq 空值保留库内旧值**）、`batch_upsert_index_kline`、`batch_upsert_fundamentals`。三者均按批 **SAVEPOINT 隔离**：失败批次回滚后继续下一批，批次间互不影响；`batch_upsert_index_kline` 自 v3.2.1 起支持 `index_code VARCHAR(16)`（曾因指数代码超长（如 931795CNY06）在 VARCHAR(8) 上截断报错导致批次静默丢失）。

## 3. scripts/ 调度层

### 3.1 dag.py — DagExecutor 计划-执行模型

- **计划阶段** `prepare_context`：run_id → 节点集（起点+全部下游，非集合内预置 completed）→ Kahn 拓扑排序（检环）→ 每节点 INSERT dag_run_log(pending) 取 log_id → 组装 context。
- **执行阶段**：循环找依赖就绪层 → 并行执行；失败节点也标 completed（下游继续不卡死）；每步检查终止信号。
- force 仅对无依赖入口节点生效（bool 或 per-node dict）。

### 3.2 pipeline.py — 节点函数注册表 NODE_FN_MAP（16 节点）

| 节点 | 写入表 | 说明 |
|---|---|---|
| cron | dag_run_log | 纯标记节点（每个流程强制含 1 个） |
| stock_master | stock_master | 全量列表 UPSERT + 标退市（含指数/ETF） |
| kline | daily_quote | tushare 按交易日全市场（单路径） |
| index / etf | index_daily_quote / daily_quote | 同上双路径（ETF 代码段 15x/5x；断点判定当日有任一 ETF 行即完整） |
| fund | stock_fundamentals | 双路径；行业回写 stock_master |
| treemap | stock_treemap_cache | 4 指标（mcap/volume/amount/pe）三层树 |
| stats | data_stats_cache | generate_stats 全库统计（避免实时 COUNT） |
| daily_completeness | daily_completeness | 当日四类行数 + baseline |
| entity_stats | entity_stats | 首次 JOIN 基线，之后增量（SSE 日历为基准） |
| feature_compute | feature_values | 增量近 10 天 / force 全量 2000-01-01 |
| feature_backfill | feature_values | 全量 2000-01-01 起 |
| model_signal | signal_history | ACTIVE 版本（≥2 周期模型走 ML 预测多周期均值，否则规则评分）→ 末尾自动步进纸面组合 |

**日志基础设施**：`write_node_log`（pending INSERT / running 更新 / 终态写 rows+finished）；`_hb_thread` 心跳（25s 更新，**5 分钟 rows 无进展判超时 failed**）。

### 3.3 feature_compute.py — KEPL→pandas 引擎

- `_extract_lookback(公式)`：ma/pct_change→N，ema/rsi→2N，boll→20，dif/dea/macd_hist→35；v3.7 兜底=公式中最大数字。拉取起点 = start − max(lookback×2, 10) 天（下限 **2000-01-01**），**保证滚动窗口有历史、增量计算不漂移**。
- **列依赖提取**：从公式正则提取 OHLCV 列；公式含 `atr` 时**自动补 high/low**。
- **`_fetch_ohlcv` 加 `close > 0` 过滤（v3.7）**：零价停牌行（如 000004 全 0）会让"分母 0+1e-12"炸出 1e12 级脏值污染因子面板。
- 执行双路径：常用公式正则快路径 → 否则 parse_to_tree + `_execute_ast` 递归（时间序列 `groupby(stock_code).transform()`；截面 rank=同日分位 / zscore=同日标准化；自定义函数 RestrictedPython 编译缓存）。v3.7 新增 14 个内置算子实现（`_builtin_*`）注册进 registry。
- 大区间自动分片（30 天/片，单片失败不影响已完成片）；compute_all_features 不分片路径需显式传 df。
- **写入**：独立 raw connection，`DELETE 范围 + COPY FROM STDIN`（CSV 流式，任意行数不 OOM）；`_batch_insert` 对 inf→NaN、|值|>1e9 剔除（numeric field overflow 防线）。
- **完整度统计回写**：`_update_feature_stats_after_compute(feature_id, force_recompute)`（app/api/features.py）——完整度=feature_values 行数/entity_stats(stock).total_cells，写 total_effective_cells/data_completeness/missing_cells_total/actual_row_count/latest_computed_date；<0.6 自动标 data_anomaly。

### 3.4 cron_scheduler.py — 定时触发

60s 扫 `dag_flows WHERE status='published' AND cron_expr`：croniter 判到期（<70s 窗口）+ **last_run_at 幂等**（同一 cron 周期只触发一次）→ `_execute_flow_internal` → UPDATE last_run_at。

## 4. 核心数据流

### 4.a 每日定时采集（cron → 节点 → WS）

```
[cron_scheduler 60s]
 └─ 扫 dag_flows 到期（last_run_at 幂等）
     └─ _execute_flow_internal(flow_id, trade_date=今天)
         ├─ TaskManager.create_task（全局≤5 / 同flow互斥）
         ├─ 临时 DagExecutor（nodes ← dag_flows.nodes，fn ← NODE_FN_MAP）
         └─ 后台线程：prepare_context（写 pending 日志→log_ids）
             └─ 逐节点：依赖就绪 → tm.update_node(running)→WS
                 → node.fn（write_node_log + 心跳 + 采集/计算 + UPSERT）
                 → tm.update_node(终态)→WS
             → 全成功 complete_task / 任一失败 fail_task

[WS 广播协程]（事件驱动：_wake / 超时兜底 2s|30s）
  推送：dag_status · dag_log · task_progress · backfill_progress
        · feature_compute_progress · sys_metrics(30s)
```

### 4.b 历史补数（状态页按钮）

```
POST /api/data_status/backfill {type, start, end, force, batch_size}
 └─ BackfillManager.start（单任务锁→Busy 429）
     └─ 后台线程：读 stock_master 全量代码（含退市）
         → 逐批（自适应并发/跨年分段/180s超时轮询）
         → fetch_fn → writers.batch_upsert_*（UPSERT）
         → 成功批次：缺失且已上市 → 停牌标记
         → 每批 UPDATE backfill_tasks + WS backfill_progress
```

### 4.c 特征计算

```
features 表（KEPL 公式, target_entity, status=enabled）
 触发：DAG feature_compute/feature_backfill 节点 或 POST /features/{id}/compute-range
 → 拉取起点 = start − max(lookback×2,10) 天
 → _fetch_ohlcv（JOIN stock_master 按类型过滤, float32）
 → 正则快路径 | KEPL AST 递归（时序 transform / 截面 rank·zscore / 自定义函数）
 → 分片（30天/片）→ DELETE 范围 + COPY → feature_values
 → 回写 features 质量列（完整度/缺失格/最近计算日；<0.6 标 data_anomaly）
```

### 4.d 模型生命周期（v3.3.0~v3.7.0 全面强化）

```
状态机：DRAFT → TRAINING → PENDING → ACTIVE ⇄ ARCHIVED
                        └──→ REJECTED ←─┘(拒绝后可 retrain)
① 创建 POST /v1/models → 自动版本 v{max+1}.0；config 含
   label_mode(excess=N日收益−沪深300 / absolute) + feature_norm(cs_rank=逐日截面rank / none)
   + 阈值双模式(quantile top5% / absolute) + 六层交易策略 + horizon 列表
② 预检 GET /feature-check → 60/20/20 三阶段覆盖统计（口径统一 v3.3.0），缓存 config
③ 训练 POST /train → TaskManager(model_train) + TRAINING（显式 version+状态校验）
   → build_feature_wide_table（SQL PIVOT，v3.3.0 起宽表下推数据库）
   → label：Triple Barrier（absolute）或超额收益 index_forward_return（excess）
   → 特征预处理：cs_rank 时 dropna 前逐日截面 rank(pct=True)
   → 设备检测 GPU 优先（cuda，失败回退 CPU）→ Optuna TPE XGBoost 双周期
   → 每轮 UPSERT training_trials；训练进度接真实 dag_run_log
   → _backtest（engine=v2：涨跌停 买剔涨停/卖拦跌停 + T+1 + 成本约束）
   → 模型文件 data/models/{v}/xgb_{horizon}.pkl → PENDING + evaluation_report（val/test 分存）
④ 评估四仪器（ModelEval 常驻）：
   a. 归因 attribution（三基线 ideal/random/real + Brinson，engine=v2 + 绩效指标条）
   b. 策略扫描 strategy-scan（参数网格；v2 引擎可选 TopkDropout topk/n_drop）
   c. 置换检验 permutation（real vs 噪声分布，perm_test JSONB 留档）
   d. walk-forward（连续不重叠窗口逐窗对比基线 + promotion_gate 判定 PASS/FAIL 落 version_comparisons）
⑤ 激活 approve → 同 entity 旧 ACTIVE→ARCHIVED；**最近 WF 判定 FAIL 时拒绝**（force=true 覆盖）
⑥ 因子 IC 体检（v3.4）：factor_ic 节点/factor_ic.py → RankIC/ICIR/分层净值/红绿灯
   → features.ic_status（candidate/included/excluded 用户决策，重算不覆盖）
   → greedy_dedup 去冗（|ICIR| 降序贪心，|ρ|>0.7 跳过）；训练默认预选 included 因子
⑦ 信号 DAG model_signal：ACTIVE 版本 → predict_for_version 多周期均值 + NaN 缺失分支
   （cs_rank 推理端同变换；≥2 周期模型才启用 ML，否则规则评分兜底）
   → 涨停股不产生买入信号（trading_rules.signal_filter.allow_limit_up 豁免）
   → 阈值双模式（quantile/absolute）→ DELETE 当日旧（按 model_version 隔离）→ INSERT signal_history
   → 末尾自动步进纸面组合（失败不影响信号）
⑧ 健康 DAG model_health：forward 回填 / 止损了结 / 胜率分档 / 滚动 RankIC（>0.005 HEALTHY，
   <0 DEGRADED 触发飞书告警）/ 纸面 EOD 净值 → ir/alpha/beta/excess/turnover 绩效列
⑨ 纸面组合 DAG paper_portfolio：v2 内核 + 种子账户续跑；EOD 幂等；同日已步进则跳过
```
