# K道量化平台 - 模型训练与回测模块优化设计方案（完整版）


## 一、模块概述

### 1.1 模块定位

模型训练与回测模块是K道量化平台的 **“策略研发中心”** 。它独立于DAG流程编排体系，提供从特征选择、模型训练、回测评估到上线部署的完整模型生命周期管理能力。

**独立性说明**：本模块与DAG流程管理模块**解耦**，主要面向量化研究员的日常研发场景（手工调参、版本对比、策略迭代），以“人工触发 + 版本管理”为主，不依赖DAG调度。

### 1.2 核心设计原则

| 原则 | 说明 |
| :--- | :--- |
| **版本即快照** | 每个模型版本完整记录特征配置、超参数、训练数据范围、交易规则，确保100%可复现 |
| **策略范式可选** | 同时支持截面排序策略与时序逐股策略，用户根据研究目标自由选择 |
| **特征可溯源** | 从特征选择到训练数据拉取，每个环节的特征质量均被记录和可视化 |
| **回测可诊断** | 每笔交易记录完整上下文，支持精细化的归因分析 |
| **审批可管控** | 模型上线需经过评估审批流程，防止未经验证的策略进入实盘 |

## 二、核心功能设计

### 2.1 优化点一：新建版本时特征选择与实体类型绑定

#### 2.1.1 功能目标

- 用户可从系统特征中心选择特征
- 指定模型针对的实体类型（个股/ETF/指数/全局）
- 特征选择器按实体类型自动过滤
- 展示特征质量指标（完整性、缺失率、依赖数量）

#### 2.1.2 数据模型扩展

在模型版本表 `model_versions` 中增加以下字段：

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `strategy_type` | VARCHAR(16) | 策略范式：`cross_sectional` / `time_series` |
| `entity_type` | VARCHAR(16) | 实体类型：`stock` / `etf` / `index` / `global` |
| `feature_list` | JSON | 选择的特征名称列表，如 `["ma5", "rsi14", "bias_5d"]` |
| `feature_full_config` | JSON | 特征元数据快照，用于版本复现 |
| `trading_rules` | JSON | 交易习惯配置（仓位管理、止盈止损、成本模型） |

### 2.2 优化点二：策略范式支持

#### 2.2.1 支持的策略范式

| 策略范式 | 适用场景 | 回测执行逻辑 | 标签定义方式 |
| :--- | :--- | :--- | :--- |
| **截面排序** | 多因子选股、相对强弱 | 按日预测全市场 → 排序 → 取Top N调仓 | 预测未来收益率，按截面排序 |
| **时序逐股** | 趋势跟踪、反转策略 | 逐只股票按日预测 → 独立买卖决策 | 预测涨跌分类或未来收益率 |

#### 2.2.2 回测执行器抽象

```python
class BacktestExecutorFactory:
    @staticmethod
    def get_executor(strategy_type: str):
        if strategy_type == 'cross_sectional':
            return CrossSectionalBacktestExecutor()
        elif strategy_type == 'time_series':
            return TimeSeriesBacktestExecutor()
        else:
            raise ValueError(f"Unsupported strategy type: {strategy_type}")
```

### 2.3 优化点三：交易习惯阈值配置

#### 2.3.1 配置分类

| 分类 | 配置项 | 说明 | 推荐范围 |
| :--- | :--- | :--- | :--- |
| **资金仓位管理** | 单票仓位上限 | 单只股票最大资金占比 | 截面：10-20% / 时序：5-10% |
| | 最大持仓数量 | 最多同时持有股票数 | 截面：20-50只 / 时序：5-10只 |
| | 总仓位上下限 | 最低/最高总仓位比例 | 下限30% / 上限100% |
| **进出场风控** | 固定止损 | 亏损达到此比例强制卖出 | -5% ~ -10% |
| | 止盈阈值 | 盈利达到此比例可锁定利润 | 15% ~ 30% |
| | 移动止盈 | 盈利回撤触发线 | 5% |
| | 信号阈值 | 预测分需达到的最小值 | 截面：Top% / 时序：绝对值 |
| | 调仓频率 | 多久调仓一次 | daily/weekly/monthly |
| **成本与冲击** | 手续费率 | 双边佣金+印花税+过户费 | 0.15% ~ 0.2% |
| | 滑点 | 买卖价差冲击 | 0.05% ~ 0.1% |
| | 流动性限制 | 买入量不超过当日成交量比例 | 5% ~ 10% |

### 2.4 优化点四：特征数据质量可视化

#### 2.4.1 功能目标

在训练前/后展示特征在训练集、验证集、测试集上的质量指标，辅助研究员判断数据有效性。

#### 2.4.2 质量指标

| 指标 | 计算公式 | 阈值 |
| :--- | :--- | :--- |
| **完整度** | 非空行数 / 总行数 | >95%绿 / 80-95%黄 / <80%红 |
| **异常值率** | 超出(mean±3σ)的行数 / 总行数 | <1%绿 / 1-5%黄 / >5%红 |
| **分布偏移** | KS统计量（训练 vs 验证） | <0.05绿 / 0.05-0.1黄 / >0.1红 |
| **特征相关性** | Pearson相关系数 | >0.8红（建议去冗余） |

#### 2.4.3 数据模型

```json
{
  "train": { "ma5": { "completeness": 0.985, "outlier_rate": 0.002, "mean": 12.34, "std": 3.21 } },
  "validation": { "ma5": { "completeness": 0.965, "outlier_rate": 0.003, "mean": 12.56, "std": 3.45 } },
  "test": { "ma5": { "completeness": 0.921, "outlier_rate": 0.004, "mean": 12.78, "std": 3.67 } },
  "distribution_shift": { "ma5": { "ks_statistic": 0.023, "p_value": 0.89 } },
  "correlation_matrix": { "ma5_rsi14": 0.32, "ma5_bias_5d": 0.85 },
  "diagnosis": "ma5与bias_5d高度相关(0.85)，建议去冗余。"
}
```
