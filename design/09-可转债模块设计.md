# 09 · 可转债模块设计

> 版本：v1.0（2026-11-21）
> 目标：把可转债纳入本地数据与产品：数据采集/存储 → 个股详情关联 → 独立可转债列表/分析/策略/详情。
> 口径：规则评分与策略池，不构成投资建议。

## 1. 数据源

| 接口 | 权限 | 用途 | 调用频率 |
|---|---|---|---|
| `cb_basic` | 2000 积分 | 转债基础信息/条款/转股价/规模 | 每日 1 次 |
| `cb_daily` | 2000 积分 | 按交易日全市场日行情 | 每日 1 次；历史补数按交易日 |
| `cb_share` | 2000 积分 | 最新转股比例/剩余规模快照 | 每日 1 次 |
| `cb_call` | 无权限 | 已公告强赎 | 不接入 |

`cb_call` 不可用，强赎观察用：停止转股/退市日期 + 正股 130% 强赎线近似（非公告口径）。

## 2. 数据模型

| 表 | 主键 | 说明 |
|---|---|---|
| `cb_basic` | `bond_code` | 每债基础信息，含条款原文、转股价、规模、上市/退市/转股日期 |
| `cb_daily` | `trade_date, bond_code` | 日行情；`vol` 手、`amount` 万元（Tushare 原口径） |
| `cb_share` | `bond_code` | 最新转股/余额快照（每日覆盖，不存历史） |

转债独立成域，不进 `daily_quote`/`stock_master`，避免污染 ETF 分类、treemap 与模型扫描域。正股仍用 `daily_quote`。

## 3. 采集链路

- 适配器：`TuShareAdapter.fetch_cb_basic/fetch_cb_daily/fetch_cb_share`，全部走 `TushareQuota.consume()`。
- 写入：`crawler/writers.py::batch_upsert_cb_basic/cb_daily/cb_share`，主键 `ON CONFLICT` 幂等。
- 服务：`crawler/cb.py::sync_basic/sync_daily/sync_share/sync_range`；`sync_range` 断点续跑，配额熔断。
- CLI：`python -m scripts.cb_sync --start 2023-01-01 --end today`；首次近 3 年约 940 个交易日、940 次 `cb_daily` 调用。
- DAG：独立流程「可转债数据」`cron → cb_daily`，每日 18:40；`cb_daily` 也注册进通用补数 `_EXT_COLLECTORS`。

## 4. 分析与策略

统一指标（`app/cb_analytics.py`）：

- 转股价值 = `100 / 转股价 × 正股收盘`
- 转股溢价率 = `转债价 / 转股价值 - 1`
- 双低 = `转债价 + 溢价率×100`
- 纯债价值/纯债溢价：票面利率 + 到期年限近似折现（3.5%）
- 换手率 ≈ `成交金额(万元)×10000 / 剩余规模`
- 强赎观察：`强赎线 = 转股价×130%`；正股距强赎线、近 30 天达标天数（≥15 天提示）
- 规则评分 0–100 + 标签（进攻/均衡/防守/回避）+ 理由/风险标记

策略池：

| 策略 | 条件 |
|---|---|
| 低溢价进攻 | 溢价 ≤20%、价 ≤140、余 ≥1 亿、正股 > MA20 |
| 双低防守 | 价 ≤130、溢价 ≤40%，按双低排序 |
| 小盘弹性 | 剩余 ≤5 亿、价 100–150、溢价 ≤40% |
| 防守债性 | 价 ≤115、纯债溢价 ≤20%、余 ≥2 亿 |
| 风险回避 | 价 ≥150 / 溢价 ≥80% / 余 <0.5 亿 / 90 天内到期 / 30 天内停止转股或退市 / 正股站上强赎线 |

## 5. API / 前端

- `/api/cb/overview`：数据日期、总量/活跃、中位数、策略池计数与 Top。
- `/api/cb/list`：筛选/分页/排序（评分、价、溢价、双低、正股涨跌、规模、换手、价格分位）。
- `/api/cb/coach`：辅导侧栏（市场概况 + 规则建议 + focus/risk 监控池）。
- `/api/cb/{bond_code}`：详情 + 近 250 日价格/转股价值/溢价。
- `/api/cb/{bond_code}/daily`：详情图数据。
- `/api/stock/{code}/convertible-bonds`：正股关联转债。
- `/api/stock/{code}/cb-linkage`：正股 × 转债联动分析（对齐日线、相关/滚动相关/β/区间收益/溢价）。
- 前端：一级导航「可转债」（`#/bonds`，tab=列表/策略/分析）；转债详情 `#/bond/:code`；个股详情右侧「可转债」卡片可点击进入。
- 个股详情「可转债」卡片右侧有「联动」入口，打开 `CbLinkageDrawer.vue`：归一走势 + 溢价、20 日滚动相关、收益散点、相关/β/区间收益解读。
- 右侧「转债辅导」侧栏（`BondCoach.vue`）：投资要领 + 规则建议 + focus/risk 监控池，行点击进转债详情。

## 6. 验证记录

- 2026-11-21：`cb_basic` 1181 条；`cb_daily` 2026-11-20 316 条；`cb_share` 257 条。
- 近 3 年回补完成：`cb_daily` **437,414 行 / 940 个交易日**（2023-01-03 ~ 2026-11-20），CLI 一次性补齐（939 新天 / 1 天已存在）。
- 全量历史补齐：Tushare `cb_daily` 最早可用 **2019-01-02**；补齐 2019-01-02 ~ 2022-12-30 后，`cb_daily` 达 **745,200 行 / 1912 个交易日**。
- `/api/cb/overview`：1181 总量 / 328 活跃 / 中位价 119.37 / 中位溢价 68.2%；列表/详情 API 延迟约 1s。
- 前端列表/策略/散点、转债详情（250 根历史图）、个股卡片链接均已实测。
- 「转债辅导」侧栏实测：概况 + 投资要领 + focus 6 只 / risk 6 只，行点击进转债详情。

## 7. 非目标

- 不做已公告强赎（无 `cb_call` 权限）、不做信用评级/违约概率。
- 不做可转债分钟/tick、不做自动交易。
- 推荐为规则筛选，不构成投资建议。
