## 阶段二：特征管理（模块一 + 模块三）

### 迭代 2.1 — KEPL 解析器后端 【已完成】

**功能点：**
- KEPL 公式解析器（词法分析 + 语法分析 + AST）
- 字段引用校验（裸字段、`current.`、`stock.`、`index[''].`）
- 聚合函数校验（参数必须是集合形式）
- 时序函数校验（参数必须是当前行字段）
- 6 类错误拦截（裸露外部数据源、聚合参数错误、时序参数错误、缺少 current、全局用裸字段、未注册引用）

**自动测试点（全部用 curl 调后端接口测试）：**
- 合法公式 `close / ma(close, 5) - 1` → 返回 AST JSON
- 非法公式 `index.close` → 400 + "请使用 ['代码'] 指定个体"
- 非法公式 `avg(close)` → 400 + "请使用数据源集合形式"
- 非法公式 `ma(stock.close, 5)` → 400 + "不能接收集合"
- 实体选 global，公式含 `close` → 400 + "禁止使用裸字段"

**人工验收点：**
- [ ] 无需前端页面，后端 API 返回正确错误提示即可

### 迭代 2.3 — 特征详情页 + 质量仪表盘 + 诊断面板 + 数据预览 【部分完成：缺热力图/饼图后端数据API】

**功能点：**

**A. 详情页顶部信息卡（路由 `/features/:id/detail`）：**

- ⏳ 待计算格子数（若 > 0 显示"进行中"标识）
- 🚫 不适用格子数（上市前/退市后/停牌，灰色显示）

**C. 依赖关系图（缩略版）** `§2.3.2`：
- 上游依赖（该特征依赖谁）→ 绿色箭头

**D. 数据缺失诊断面板（折叠展开）** `§2.3.3`：
- 视图一：二维缺失热力图（缩略版）

- 视图二：缺失归因饼图
  - 停牌导致 vs 非停牌异常缺失
  - 若异常缺失 > 50% → 🔴 "大部分缺失非停牌导致，请检查计算逻辑或数据源"

**E. 数据预览（分页加载）** `§2.3.4`：

## 阶段四：DAG 编排与执行监控（模块六~八）

### 迭代 4.1 — 可视化流程编排

**功能点：**
- DAG 画布（拖拽节点、连线、删除）
- 流程保存（JSON 结构化存储）
- 流程版本管理（新建版本 → 编辑 → 发布）
- Cron 调度配置
- 7 项流程校验规则：
  1. 有向无环（无循环依赖）
  2. 单一入口节点
  3. 至少一个出口节点
  4. 所有节点已正确配置
  5. 节点参数有效
  6. 节点类型已在注册中心存在
  7. 上下游数据类型匹配

**自动测试点：**
- `POST /api/dag/flows` 保存流程 → JSON 含 nodes + edges
- 检测循环依赖 → 400
- 无入口节点 → 400 "流程缺少入口节点"
- 引用未注册节点类型 → 400

**人工验收点：**
- [ ] 拖拽节点到画布 → 连线 → 保存 → 刷新后恢复
- [ ] 发布流程 → 状态变「已发布」→ Cron 自动启动

### 迭代 5.3 — 回测引擎 【部分完成：缺独立模块 + backtest_records/trades 表】

**功能点：**
- 策略模式工厂（CrossSectionalBacktest / TimeSeriesBacktest）
- 三层仓位约束：
  1. 资金约束：`current_equity × single_stock_cap / buy_price`
  2. 流动性约束：`≤ 当日成交量 × volume_ratio_limit`
  3. 整数手约束：`// 100 * 100`
- 止盈止损执行（固定止损 + 止盈 + 移动止盈）
- 成本扣除（佣金 + 印花税 + 滑点，买卖双向）
- 交易明细完整记录（买入前后仓位/资金、卖出前后仓位/资金、盈亏归因）
- `backtest_records` 表（每次回测的汇总：版本、起始资金、终值、夏普、胜率、回撤、年化）
- `backtest_trades` 表（每笔交易明细：方向、价格、股数、成本、盈亏、前后仓位）
- 评估指标计算（夏普、胜率、最大回撤、年化收益、盈亏比）

**自动测试点：**
- With mock 数据（100天 × 3只股票），资金 1M，仓位上限 20%
  - 每笔交易 shares ≤ 成交量 × 10%
  - 总金额 ≤ 初始资金
  - 止损触发时卖出价 ≤ 买入价 × (1 - stop_loss)
  - trade_detail 含完整上下文

**人工验收点：**
- [ ] 训练完成后 → 评估页展示夏普/胜率/回撤/年化
- [ ] 交易明细表格展示每笔交易的完整上下文
- [ ] 每笔 shares 合理（百股级别，非万亿）
- [ ] 下载 CSV → Excel 打开不乱码
