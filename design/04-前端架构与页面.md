# 04 — 前端架构与页面

> K道（Stone）web-v2 · 文档基准：代码版本 v3.2
> 技术栈：Vue 3（Composition API + `<script setup>`）· Vite 5 · Pinia 3 · Naive UI 2.38 · ECharts 5 · Vue Flow · Monaco Editor。**无 vue-router，自研 hash 路由**。

---

## 1. 工程结构

```
web-v2/
├── index.html          # 入口（body 深色底、tabular-nums 数字等宽、禁缩放）
├── vite.config.js      # dev :3000，proxy /api|/health → :8000（ws:true, timeout 120s）；build → dist/
├── src/
│   ├── main.js         # Monaco worker 先行加载；axios 拦截器
│   ├── App.vue         # 根组件（主题/登录态/tab栏/14页面挂载/标题联动）
│   ├── stores/         # 5 个 Pinia store（§3）
│   ├── utils/
│   │   ├── ws.js       # WebSocket 管理（§5）
│   │   └── monaco-worker.js
│   └── components/     # 24 个 .vue（14 页面 + 7 子组件，§4）
```

**main.js axios 拦截器**：
- 请求：`localStorage.token` → `Authorization: Bearer`。
- 响应 401：**排除 `/api/login`**（登录失败显示错误提示而非闪屏），其余 401 → 清 token → `location.reload()` → App 渲染 LoginView。

## 2. 路由（stores/nav.js 自研 hash 路由）

核心状态：`tab`（页面字母）、`dcode`（个股代码）、`fid`（特征 id）、`flowId`（null=列表 / 'new'=新建 / 数字=编辑）、`prevTab`（返回栈）、`modelEntity/modelVersion/modelTab`、`statusMonth`、`stockFundType` 等。

| Hash | tab | 页面 |
|---|---|---|
| `/` `/portfolio` | `p` | 持仓 |
| `/market/:date` | `m` | 选股树图 |
| `/signals` | `s` | 买点信号 |
| `/stocks` | `l` | 个股列表 |
| `/status?month=&bf_page=` | `x` | 数据状态（query 恢复月份/日志页码） |
| `/models/:entity[/:version][?tab=]` | `a` | 模型管理 |
| `/functions` | `f` | 函数管理 |
| `/features?page=&entity=&status=&search=` | `e` | 特征管理 |
| `/dag-flows` · `/dag-flows/new` · `/dag-flows/:id` | `g` | DAG 流程（列表/新建/编辑） |
| `/dag-logs/:id[/:task_id]` | `q` | 流程执行日志（task_id 深链） |
| `/dag-flow-view/:id` | `r` | 流程运行查看 |
| `/feature/:id` | `v` | 特征详情 |
| `/detail/:code` | `d` | 个股详情 |
| `/stock-fund/:type` | `u` | 证券主档列表二级页（type: stock/index/etf） |

`parseHash()` 初始化+popstate 监听；`syncHash()` pushState 反写。导航 API：`switchTab / showDetail / showFeatureDetail / showFlowEditor` 及对应 `backFrom*`。

## 3. Pinia Stores

| Store | 职责 |
|---|---|
| `auth` | token/username 持久化 localStorage；`setToken` 同步 axios 默认头；`logout` 清全部 |
| `nav` | 上节路由状态机 |
| `model` | 模型页状态：versions 列表（`GET /api/v1/models?entity=`）、选中版本、detailTab（basic/indicators/train/eval/live）、状态徽章映射、deleteCheck/deleteVersion |
| `market` | 树图页 `selDate` + 行业下钻栈 |
| `theme` | 三态 light/dark/auto（auto：8:00–19:00 浅色，60s tick）；输出 `naiveTheme` + `colors` 色板 |

## 4. 页面组件（App.vue 注册的 14 页面）

Tab 栏 9 个一级按钮：`p m s l a f e g x`；其余为二级页。

| tab | 组件 | 功能要点 |
|---|---|---|
| `p` | **PortfolioView** | 汇总卡（A股配色：涨红跌绿）；持仓表（成本/现价/盈亏%/今日信号）；新增/编辑/删除；"详情"弹窗看加减仓历史 |
| `m` | **TreemapView** | ECharts treemap；指标 mcap/volume/amount/pe；行业 L1/L2 下钻；叶子点击进个股详情；⚡生成（dag_trigger treemap） |
| `s` | **SignalsView** + SignalStatsView | 信号列表（北京时间今天默认）+ 效果追踪（胜率趋势/收益分布/行业/Top 股表）；⚡生成 model_signal |
| `l` | **StocksView** | `/api/stocks` 分页；分类切换/搜索/服务端排序 |
| `a` | **ModelView**（+ Training/Eval/Live 子组件） | 左版本列表+右详情；实体切换；5 子 tab：basic（配置）/ indicators（**特征预检** train·val·test 覆盖）/ train（WS 驱动 4 步进度+停止）/ eval（审批/报告/策略扫描/归因）/ live（健康度+信号）；创建弹窗含六层交易策略面板 |
| `f` | **FunctionView** | 函数注册表；Monaco 编辑 Python（首参 df）；签名自动解析参数表；🧪试运行（耗时着色）；AI 生成；版本回滚；右侧编码规则静态栏 |
| `e` | **FeatureView** | 特征注册表；Monaco 编辑 KEPL + 🔍验证（依赖自动提取）；AI 生成公式；**📥特征补数**（WS 精确匹配 task_id 进度）；🔗依赖图（ECharts force） |
| `g` | **DagFlowEdit** | 双模式：列表（流程表+发布/执行/日志/查看）+ 编辑（**Vue Flow 画布**：节点面板过滤 cron、拖拽吸附 20px、连线自动选最优 Handle 方向、BFS 自动布局、缩放百分比、**位置随保存持久化**）；cron 节点强制存在，双击开 Cron 可视化构建器（每N分/时/天/周/月 + cronstrue 中文预览 + 校验）；发布/下线确认弹窗填变更说明 |
| `x` | **StatusView** + BackfillModal | 数据运维中枢：概览条/数据明细卡（点击→stock-fund 二级页）/数据源健康灯/交易日历月历（完整度着色+点击弹明细）/服务器监控（WS）/全局偏好/**历史补数 6 按钮**（弹窗：日期范围+续传/强制+并发；运行条 WS 驱动可取消）/补数日志分页 |
| `u` | **StockFundView** | 证券主档+基本面宽表（50/页，字段全量）；"历史"弹窗分页；返回→状态页 |
| `d` | **DetailView** | 5 张 ECharts 联动（K线+BOLL/成交量/MACD/RSI/PE 分位）；复权切换；dataZoom 默认近 60 日；hover 十字线联动行情表；右栏基本面 |
| `v` | **FeatureDetail** | 3 tab：基本信息（质量仪表盘 4 卡+上下游）/ 缺失诊断（归因饼图+120日×TopN 热力图）/ 数据预览 |
| `q` | **FlowLogView** | 左任务列表（按流程过滤）+右详情（逐节点 started/finished/rows/error）；hash 深链 task_id |
| `r` | **FlowRunView** | 只读画布+总进度条；▶执行（选日期）；点节点开详情；WS 实时刷节点状态 |

子组件：`SignalStatsView`（s 内嵌）、`BackfillModal`（x 内嵌）、`ModelTraining/ModelEval/ModelLive`（a 内嵌）、`DagNode`（Vue Flow 自定义节点：四向 Handle、状态着色）、`MonacoEditor`（python 薄封装）、`LoginView`。

## 5. WebSocket（utils/ws.js）

- URL：`origin.replace('http','ws') + '/api/ws/dag?token='`。
- **自动重连**：指数退避 `min(1000×2^n, 30000)`，上限 20 次；onopen 重置。
- **`addWsListener(fn)` 返回取消函数**——所有组件 onUnmounted 必须调用（防 v-if 切 tab 泄漏，v3.2 已全量修复）。
- App.vue 头部：连接指示灯（1s 轮询）+ 手动重连按钮。

## 6. 样式与主题

- `n-config-provider(:theme)` 接 store；App.vue 根容器把 `theme.colors` 注入 CSS 变量 `--c-bg / --c-text / --c-card-bg / --c-border...`，全组件以 `var(--c-*)` 消费 → 主题切换全站生效。
- ECharts 无法用 CSS 变量的部分直接取 `theme.colors`，树图 watch `isDark` 重绘。
- **市场配色约定**：涨/看多 `#ef4444`（红），跌/看空 `#10b981`（绿）。
- 表格数字 `font-variant-numeric: tabular-nums` 防跳动。

## 7. 开发与构建

```bash
cd web-v2
npm run dev      # :3000，proxy → :8000
npm run build    # → dist/（生产 volume 挂载，rsync 即发布）
npm run test:e2e # Playwright
```

注意事项：
- Monaco worker 必须在 monaco-editor import 之前加载（main.js 第一行）。
- 跨平台开发时 node_modules 需在本机重装（rollup 原生模块按平台分发）。
- 组件内新增 WS 监听务必保存 `addWsListener` 返回值并在卸载时调用。
- 日期显示一律北京时间（`Intl.DateTimeFormat('zh-CN',{timeZone:'Asia/Shanghai'})`），勿用 `toISOString()`。
